# PeakFitScience FULL ENGINE

## Features
- ROOT histogram browsing (cb/CB_ADC_xxx)
- interactive fitting (Gauss + exp)
- live fit updates
- mouse-controlled ROI
- session save/load
- CSV export

## Controls
- LEFT CLICK  → xmin
- RIGHT CLICK → xmax

## Build
mkdir build
cd build
cmake ..
make

## Run
./peakfit data.root
